# ChessPuzzleBot روی GitHub Actions — اجرای دائمی، خودکار و رایگان 🎉

این ریپو هر روز **خودش** ویدیوهای یوتیوب می‌سازد و آپلود می‌کند. شما کاری لازم نیست بکنید.

## چطور کار می‌کند
- ورک‌فلو `.github/workflows/daily.yml` **هر ۲ ساعت** یک‌بار اجرا می‌شود.
- `bot.py --cron` خودش تصمیم می‌گیرد آپلودی در نوبت هست یا نه (بر اساس `config.json`).
- **کوتای پلکانی هفتگی** (از `launch_date` شمرده می‌شود):
  هفتهٔ ۱: روزی **۲ ویدیو** — هفتهٔ ۲: **۳** — هفتهٔ ۳: **۵** — هفتهٔ ۴ و بعد: **۸ برای همیشه**
- هر ویدیو = **۵ پازل × ۲ دقیقه = ۱۰ دقیقه** (۱۶:۹، بورد بزرگ سمت چپ، متن‌های انگلیسی سمت راست) + **تامنیل اختصاصی**
- هر ویدیو **۲ شورت ۱۵ ثانیه‌ای** (۹:۱۶) از همان پازل‌ها می‌گیرد که به ویدیو لینک می‌شوند → روزی ۴ شورت در هفتهٔ ۱.
- جواب هیچ پازلی روی بورد نمایش داده نمی‌شود (فقط «Comment the answer!»).
- ضد تکرار: هر اجرا با تاریخچهٔ یوتیوب سینک می‌شود، پس هیچ پازلی دو بار آپلود نمی‌شود و
  شماره‌گذاری Puzzle #N هم از همان تاریخچه ادامه پیدا می‌کند (حتی روی رانرهای تازه).
- استخر **۱۰۰,۰۰۰ پازل معتبر** (ریتینگ ۱۴۰۰–۲۵۰۰، تک‌تک اعتبارسنجی‌شده با python-chess)
  داخل همین ریپو commit شده (`puzzles.jsonl`) — نیازی به دانلود نیست.

## قدم ۱ — Secrets یوتیوب (فقط یک بار)
توی ریپو: **Settings → Secrets and variables → Actions → New repository secret**

هر کدام از این دو نام‌گذاری کار می‌کند:

| اسم Secret | مقدار |
|---|---|
| `YT_CLIENT_SECRETS` | کل محتوای JSON فایل `client_secrets.json` |
| `YT_TOKEN` | base64 فایل `token.pickle` (ویندوز: `certutil -encode token.pickle out.b64`) |

یا معادل‌های قدیمی: `CLIENT_SECRETS_B64` و `TOKEN_PICKLE_B64` (base64).

> ⚠️ فایل‌های لاگین (`client_secrets.json` و `token.pickle`) هرگز داخل ریپو commit نمی‌شوند.

## قدم ۲ — اجرا
- تب **Actions** → اگر غیرفعاله، «Enable workflows» را بزن.
- ورک‌فلو «Daily Chess Videos» به‌صورت خودکار هر ۲ ساعت چک می‌شود؛
  برای تست فوری: **Run workflow** → نتیجه در لاگ همان اجرا.

## نکته‌ها
- ساعت‌های اسلات بین `first_upload_time` تا `last_upload_time` در `config.json` پخش می‌شوند (زمان اجرای رانر UTC است).
- کرون گیت‌هاب گاهی چند دقیقه تأخیر دارد — طبیعی است.
- همه‌چیز از YouTube قابل بازیابی است: اگر رانر پاک شود، ربات از روی ویدیوهای آپلودشده
  تعداد پازل‌ها و شماره‌ها را می‌فهمد و از همان‌جا ادامه می‌دهد.
